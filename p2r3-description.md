**P2R3 Converter Opener Extension**

A community-developed browser extension that allows users to easily open and convert files, created by [p2r3](https://github.com/p2r3/convert) on GitHub.

**Functionality**

This extension provides a convenient way to convert and open files, streamlining your workflow and saving you time. With its simple and intuitive design, users can easily access and utilize its conversion features.

**Key Features**

* File conversion and opening capabilities
* Compatibility with multiple file formats
* Easy-to-use interface for seamless conversion and opening

**Note**: This extension is not affiliated with the owner of the site and is a community-made project. It is provided as-is, and users are free to modify and contribute to it on GitHub: https://github.com/p2r3/convert.
